# 📘 COURSE PROJECT – DATA SCIENCE  
# LongChau Pharmacy Sales Analysis & Predictive Modeling (2024–2025)



## 📌 Overview  

This project focuses on analyzing real-world sales data from **LongChau Pharmacy**, collected between **October 2024 and December 2024**.  
The goal is to **extract business insights**, understand customer behavior, and develop **predictive models** that identify top-selling products.

The project includes three major components:

1. **Data Collection & Web Scraping**  
2. **Data Cleaning, Transformation & Exploratory Data Analysis (EDA)**  
3. **Machine Learning Models for Ranking and Predicting Top-Selling Products**

---

## 🛠️ Tech Stack

### **Languages & Libraries**
- **Python 3.10+**
- **Selenium** – automated data collection  
- **pandas, numpy** – data cleaning & preprocessing  
- **matplotlib, seaborn** – trend visualization and statistical analysis  
- **scikit-learn** – machine learning modeling  

### **Tools & Environment**
- Jupyter Notebook / VSCode  
- ChromeDriver (Selenium)  
- Git & GitHub for version control  

---

## 📂 Project Highlights

### 🔎 **1. Data Collection**
- Collected **10,000+ sales records** from LongChau Pharmacy using Selenium.
- Extracted product names, categories, prices, customer ratings, and number of reviews.
- Implemented anti-bot handling, delay strategies, and dynamic element crawling.

### 🧹 **2. Data Cleaning & Preprocessing**
- Removed duplicates, normalized product categories, processed missing values.
- Transformed rating distributions and standardized numeric features.
- Feature engineering for:
  - Product popularity score
  - Rating-weighted sales score
  - Price segmentation

### 📊 **3. Exploratory Data Analysis (EDA)**
- Visualized patterns in:
  - **Customer ratings**
  - **Sales performance**
  - **Top-selling categories**
  - **Price vs. rating correlations**
- Identified key factors influencing high-selling items.

### 🤖 **4. Predictive Modeling**
Built machine learning models to classify the **top 10% best-selling products**:
- Logistic Regression  
- Random Forest  
- Gradient Boosting  

Evaluation metrics:
- Accuracy  
- Precision & Recall  
- F1-score  
- ROC–AUC
